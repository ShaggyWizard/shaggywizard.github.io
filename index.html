How I work with AI

  1. Plan it myself. I break the task down, choose the stack and architecture, and resolve open questions before any code is written.
  2. Small tasks. Models get lost on large scopes, so I split work into small specs and hand them to Claude Code agents, in parallel where possible.
  3. Three review passes. Cross-model review (Codex, Gemini, DeepSeek) plus a security audit, then automated tests with known-good and known-bad cases, then I read the diff — carefully wherever money or access is involved.
  4. Reusable tooling. Project instructions, custom skills and MCP servers for the work that repeats.
